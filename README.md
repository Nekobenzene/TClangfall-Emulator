# TClangfall Emulator · 临海台风视场模拟器

[![GitHub Pages](https://github.com/Nekobenzene/TClangfall-Emulator/actions/workflows/pages.yml/badge.svg)](https://github.com/Nekobenzene/TClangfall-Emulator/actions/workflows/pages.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

以临海住宅与自由飞行视角观察台风的交互式 Three.js 模拟器。调整台风位置、强度、风圈结构、雨强与移动，观察风雨、能见度、螺旋眼墙、景物风毁及简化风暴潮的变化。所有运行资源内嵌，支持单文件离线使用。

接手开发或在新对话中继续，请先阅读 **[项目交接文档](HANDOFF.md)**，了解当前标定、模块关系、配置迁移和验证发布流程。

## 当前进度（2026-10-25）

本轮更新风雨随机波动、峰值声画响应、暴风圈背景及瞬时能见度 / 风毁计算。两版离线 HTML、配置、编辑器与托管首页同步构建。

- 连续随机对数波动按约 10 个现实秒推进，暂停冻结，不随模拟倍率加速。暴风圈阵风的 5% / 50% / 95% 中央区间为 ±3% / ±12% / ±25%，眼墙与外围为 ±2% / ±10% / ±25%；暴风圈雨量为 ±2% / ±8% / ±15%，眼墙雨量为 ±1% / ±4% / ±8%。区间为对数对称，±25% 即参考值的 80%–125%。
- 强风峰值或快速上升段使雨雾短时加浓、加速，转折处渐入 / 渐退；125% 峰值对应额外 2 倍频率、1.3 倍显示速度。风声跟随瞬时阵风，雨声跟随瞬时雨强和雨滴运动速度；尖啸音高只随瞬时风速变化，整体升调 5%，音量保留峰值与上升速度增强。
- 暴风圈基础雨量提高约 23%，叠加由内向外减弱的弱风雨背景。保留眼墙到暴风圈较陡的风雨变化，内外边界数值连续衔接。
- 能见度同时使用瞬时雨强、瞬时阵风；155 kt 以上风速调制放缓，65 mm/h、200 kt 对应约 250 m。风毁按物体所在地完整瞬时阵风累计。

详细参数、概率含义与模型限制见[天气模型说明](docs/weather-model.md)。验证包括 18 项单元测试，以及两版页面、配置、雨雾渲染和真实音频 PCM 回归。发布使用 main 分支的 [GitHub Pages 工作流](https://github.com/Nekobenzene/TClangfall-Emulator/actions/workflows/pages.yml)。

风雨声音本轮已完成，采用用户试听确认的最终版 01：弱雨随机轻滴平滑连接连续雨声，强风加入随机尖啸、漏风气声和低沉轰鸣。声音与采样全部内嵌，默认主音量 50%，点击开启后播放。交接状态、测试记录和本机临时试听位置见 [HANDOFF.md](HANDOFF.md)，具体公式与参考限制见 [天气模型说明](docs/weather-model.md)。线上版本以对应提交的 Pages 部署结果为准。

## 快速开始

打开 **台风模拟器.html** 即可使用。Three.js、贴图、地图、建筑和天气均已内嵌，无需联网或安装。

本地与 GitHub 仓库同时保留以下两套 HTML，初始内置参数和模拟功能相同：

| 版本 | 文件 | 外部配置与编辑器 |
| --- | --- | --- |
| 仅内置参数版（线上首页） | [台风模拟器.html](台风模拟器.html) | 只使用内置参数，不读取外部配置，没有编辑器入口；运行时的滑动条和地图操作照常可用 |
| 可配置版 | [台风模拟器-可配置版.html](台风模拟器-可配置版.html) | 保留完整内置参数作为回退，优先读取同目录配置；主界面顶部有醒目的“配置编辑器”按钮 |

[simulator.config.json](simulator.config.json) 已配好全部当前默认数值、文案和公式，供可配置版读取和编辑器导入；[simulator.config.js](simulator.config.js) 是对应的离线兼容副本。需要离线编辑时，将可配置版、`config-editor.html` 和配置文件保存在同一目录。两套模拟器各自单独一个 HTML 也可按内置值运行。

默认收起右侧设置栏及各参数分类，优先展示观测视场。点击“设置”展开，再点分类标题查看参数。顶部“使用指南”提供操作流程和 8 步交互引导：环视缩放、楼房楼层、地图定位、风雨强度、移动时间、自由飞行、风暴潮与风毁、全屏显示。也可按主题直接跳转，边看说明边操作；结束或按 Esc 会恢复进入前的面板状态，保留主动修改的参数。手机横竖屏均可使用。

桌面布局随窗口高度分配主视窗空间，气象读数、水位、风毁和楼层控制在同一屏内显示；自由飞行速度区出现时也会自动留出空间。右栏独立滚动，设置分类最多展开一项，打开另一项会自动收起原项，并滚回设置栏顶部，从“风场沙盘”开始显示；地图内的精调位置仍可独立展开。设置栏、分类、临时场景面板及说明弹窗带短过渡动画。使用指南以明亮双层描边和缓慢闪烁的光晕标出当前操作区；动画遵循系统“减少动态效果”偏好。

主界面下方保留气象读数、当前水位、雨量与楼层选择，风毁状态移到水位 / 雨量右侧（手机窄屏换行）。阵风和能见度下方不再重复附注；风向角度与“风向”标题放在一起，天气摘要和风向箭头从右侧设置移到主视窗读数下方。视角通过场景拖动、方向键或触屏调整。

## 配置与交互编辑器

**[在线配置编辑器](https://nekobenzene.github.io/TClangfall-Emulator/config-editor.html)**，也可双击本地 `config-editor.html`。可配置版主界面顶部提供高对比的“配置编辑器”按钮，不必先打开使用指南；手机横竖屏均可直接点击。编辑器打开和预览的都是可配置版。线上首页继续不含编辑器入口，也不会受到外部配置改动影响。

1. 编辑器分为常用参数、界面文案、计算公式、公式与源码、高级数值、布局与样式、着色器及其他字符串。每项输入前都有简短用途说明；说明根据变量用途、运算位置、控件范围或 CSS 属性生成，常用物理参数另标明单位和含义。支持搜索说明文字、按文件筛选、只看已修改、单项恢复；高级项附源码位置、上下文和内置值。公式提供结果含义、单位、可修改的样例输入和即时计算结果。
2. 点“预览修改”，在新窗口运行当前修改，不写入原文件。点“导出配置 .json”得到 `simulator.config.json`，放在可配置版 HTML 同一目录，通过 HTTP 或 GitHub Pages 访问时重新加载生效；支持的浏览器也可点“保存 JSON 到文件”选择并写回该文件。默认只导出修改项，勾选“导出完整配置”包含全部内置默认。双击离线 HTML 时，另点“导出离线配置 .js”，将 `simulator.config.js` 保存到同目录。
3. 可配置版通过 HTTP 访问时先读取 `simulator.config.json`；JSON 不存在或不能解析时尝试同目录 `simulator.config.js`；双击本地 `file://` HTML 时直接读取 JS 副本，以兼容浏览器的本地 JSON 读取限制。两份均无法读取时使用内置参数。字段缺失或类型错误时逐项使用内置值，非法或非有限公式结果回退原有计算。原源码的硬编码及 HTML 内嵌默认仍保留。仅内置参数版始终不加载这两份配置。
4. `config-catalog.json` 是生成的参数目录，包含全部第一方运行代码中的数值 / 布尔常量和字符串、HTML 可见文本 / 控件数值属性，以及 CSS、GLSL 数值。当前约 7000 项，包含数组索引和采样数等高级结构项；第三方 Three.js 源码不作改动。CSS 中的颜色 HEX、JS 中的格式字符串等可通过对应完整字符串编辑。
5. 参数值、计算公式和说明文案分别配置。改写公式后，其内部常量以新公式为准；保留默认公式时仍使用原执行路径，数值项覆盖照常生效。改写完整着色器文本后，其原位置对应的数值覆盖不再叠加。单位约定与内置模型一致：风速 kt、距离 km、风暴潮和能见度 m、角速度 rad/s。

最小 `simulator.config.json` 示例（其余项使用可配置版 HTML 内置值）：

```json
{
  "version": 1,
  "values": {
    "eye.cloudClearIntensity": 180,
    "eye.cloudRotationRatio": 1,
    "weather.eyeRainStopsAt": 100,
    "weather.eyeSunStartsAt": 145,
    "weather.eyeSunFullAt": 180
  },
  "texts": {},
  "formulas": {
    "weather.visibility": "clamp(Math.log(20) / (Math.log(20) / 14000 + extinction), 55, 14000)"
  }
}
```

常用别名会映射到目录中的具体数值键，同一配置同时存在别名与具体键时，别名优先。文案键可在编辑器搜索原文字后获取。JSON 同时用于自动加载、备份和导入；离线 JS 文件内容为 `globalThis.TYPHOON_CONFIG = { ... };`。在线 JSON 与离线 JS 如同时存在，请在修改后分别导出以保持一致，或运行一次构建同步。

可编辑公式包括 `eye.development`、`eye.rainClearing`、`wind.profile`、`rain.mistTransition`、`rain.effectiveDiameter`、`weather.eyeSun`、`weather.rain`、`weather.rainExtinction`、`weather.visibility`、`surge.level`、`surge.responseSeconds`、`eye.wallHeight`、`eye.cloudCoverage`、`eye.angularSpeed`。每项可用变量列在编辑器中；支持算术、比较、条件运算、`clamp` / `smooth` 和常见 `Math` 函数，采用表达式解析器求值，不使用 `eval` / `new Function`。语法错误、未知变量、非法运算或非有限结果均可恢复到内置计算。`weather.visibility` 的 `extinction` 是有效雨雾消光系数（1/m）；`weather.rainExtinction` 另提供 `dropExtinction` 作为物理滴谱消光的参考输入。视觉过渡、物理尺寸谱、有效消光和能见度可分别调整。

### 编辑器内附的全部计算公式

在**可配置版主界面 → 配置编辑器 → 公式与源码**中，可离线查阅三个层次的参考：

- **可编辑公式**：14 个公式的用途、变量、内置表达式和源码位置。
- **全部计算表达式**：从实际源码自动提取的全部计算表达式，覆盖风场、降雨、能见度、风暴潮、风毁、云体、粒子、相机与地图等；支持按变量、表达式或源文件搜索、筛选与分页。
- **完整源码**：16 份第一方模拟模块的完整原文，包含复合函数、分段条件和着色器内公式，可展开逐份查阅；不删减、不依赖网络，不重复打包第三方 Three.js。

公式附录完整内嵌于 `config-editor.html`，随构建从源码生成，展示本版内置定义；“计算公式”分类负责修改与试算，“公式与源码”分类负责查阅完整参考，切换分类保留未导出的修改。两套模拟器主页面都不再单独显示公式查看页，公式统一放在编辑器中。

眼内低层、中层云现默认与眼墙共用同一角速度、相位与模拟时钟，修正此前眼内云仅按眼墙 0.28 倍速度旋转的差异。`eye.cloudRotationRatio` 默认 1，可自行调整。

连续云底纹理沿当地气流移动，速度默认取当地持续风的 **1.3 倍**，可用常用项“云底随风移动倍率”或 `cloud.baseWindFactor` 调整。倍率参考 Franklin 等（2003）的海上飓风低层风廓线，属于低云被气流携带的简化近似。位置按实际天气秒数累计，暂停冻结、重置清零；调风不会使纹理跳位。眼墙与眼内云继续按原有模拟时钟旋转。文献依据及适用范围见[天气模型说明](docs/weather-model.md#云底纹理的移动速度)。

开发时 `node build.mjs` 同时生成两套模拟器 HTML、编辑器和参数目录，保留已有 `simulator.config.json`，并以该 JSON 同步生成离线 JS 副本。首次没有 JSON 时从已有 JS 配置迁移，否则使用内置默认；仅在需要主动重置配置时运行 `node build.mjs --reset-config`。未知旧键会被忽略，可在编辑器导入时查看数量；可配置版的配置来源、文件名与回退信息可通过 `SimulatorConfig.diagnostics()` 查看。`node build.mjs --pages` 将内置参数版作为首页，同时保留可配置版、编辑器、配置文件和目录的独立地址。

## 风场与天气

- 输入为静止参考的最大一分钟持续风，20–200 kt。
- 低于 67 kt 不设眼和眼墙，但中心风速仍降低；低于 34 kt 不设暴风圈。从 67–110 kt，眼墙增强与风眼风速减弱由零平滑发展到完整结构，最大风速半径也连续收缩；地图眼和眼墙线条同步淡入。无效结构的参数暂存，增强后恢复。四个可调半径：风眼、核心眼墙外界、暴风圈、外围影响圈，自动保持从内到外的次序。暴风圈为自定义结构边界，不是固定风速的等值线。
- 径向持续风采用 Willoughby 等（2006）函数族的适配：内侧幂律上升，峰值平滑连接，外侧快慢双指数衰减。强台风增加快速衰减分量，眼墙附近变化较快，外围保留缓降长尾；圈线处没有风速断点。自定义半径参与尺度选择，保留轻微不对称与移动风场；这是地面场景的启发式模型，并非原论文完整拟合式。
- 成熟台风暴风圈基础雨量提高约 23%，并叠加向外递减的弱背景；持续风最多额外增加 6%、雨量最多增加 3 mm/h（进入雨强滑条及 0.90 总倍率前），与眼墙及外围平滑连接。暴风圈内雨量向内略增，至眼墙外侧陡增；100–150 kt 时，眼内干燥区连续向眼墙内缘扩展。150 kt 起，雨墙随云底内缘掠过而骤增，默认 14.775–15.225 km 完成过渡，中心仍保持干燥。无眼系统使用更强的向内增雨梯度。
- 外围影响圈向暴风圈靠近，持续风逐步增强；瞬时阵风在一分钟参考风周围按所在区域的对数概率分布连续随机变化。外围阵雨保留独立脉冲。极大外围暴雨较罕见，但可以强于眼墙，表现为大量密集长雨丝及极低能见度；阵雨间隙偶有多云和晴空。
- 外围影响圈之外为下沉晴空，仍有较弱、可变化的风和阵风，不会突然变成完全静风。阵风对数比例跨圈线保持连续；阵雨概率从圈内平滑降至边界的零，匹配圈外晴空。向内阵雨出现概率增加；暴风圈和眼墙分别使用更稳定的连续雨量波动。
- 北半球逆时针环流，向心流入 15°，把移速的 65% 作为向量叠加。前进去向右侧为危险半圆、左侧为相对较弱的安全半圆，本地风速可能超过静止参考输入。
- 弱系统中心保留雨；67–100 kt 眼内雨量连续减少，约 100 kt 眼中心趋于无雨；150 kt 左右开始见阳光，至 180 kt 逐渐成为明亮晴空，190 kt 起眼内低中云清空。固定雨量时，画面雨滴在 45–135 kt 逐渐变小、变密，95–110 kt 保留短雨丝，到 135 kt 呈细密雾状。基础粒子比上版增加约 36%，充分细化时总量增加约一倍、最大池 270000 条；基础下落显示倍率从物理终速的 3.6 倍渐变到 0.75 倍，再乘随风增强、200 kt 达到 2 的显示速度增益；高风拖尾保留至少同雨量静风参考长度的一半，不透明度在原曲线上乘 0.72。物理谱在固定雨量时不随水平风强制变细，仍按通量归一化。视觉阈值为可调设定。100 kt 后树干弯曲显著增大。
- 大雨即使在较弱风中也会出现疏密移动的白色雨幕，较慢地随风漂移并保留下落分量。雨滴与不均匀雨雾采用同量级的小幅世界坐标浓度波动：雨滴约每秒 1.45 个周期、雨雾约每秒 1 个周期，波长随流速变化；连续透明度调制保留全部雨粒，避免大片空雨区。暂停时停止，移动视角有空间视差。“去除雨雾”保留雨丝疏密与运动白雾。界面显示背景平均能见度，各方向的遮蔽可随雨团变化。
- 仅地形或水面上方约 4 m 内保留薄而平的白雾，其余为竖向体积雾墙：大小、浓淡各异，长轴大致顺风，随风搬运并轻微变形。雾墙长、高、厚分别放大 35%，当前长约 38–149 m、高 32–135 m、厚 7–27 m；随风搬运速度提高 25%。连续密度在外沿缓慢降至零，远处先渐隐再循环补位；从侧面、内部或高楼观察都保留体积，穿行时不会被相机近裁剪面切断。接近楼房时淡出，与建筑相交时隐藏，移出后用 2.5 秒恢复浓度，避免穿墙后突然出现。运动白雾不透明度倍率从 0.24 降到 0.16；天空背景上完全隐去，不产生青绿色色块，保留对楼房、地面和海面的遮蔽。暂停后自由飞行能穿过静止雾墙。尺寸与浓度为视觉参数，气象能见度标定保持原样。
- 能见度按 MOR 5% 定义与有效雨雾消光计算，以用户修正的无风 75 mm/h → 350 m 定标（70–80 mm/h 约 300–400 m）。固定雨量时，120 kt 以下风不额外增强消光，120 kt 后平滑增强，155 kt 后用较缓的对数尾段放缓；采用瞬时雨强与瞬时阵风；固定 65 mm/h，本地阵风 170 kt 约 276 m、200 kt 约 250 m。无雨时不单独压低能见度。这是可调场景标定，未宣称为普适实测曲线；物理雨滴谱消光另行保留供参考与改式使用。
- 独立雨强为 0–200%，主要调制暴风圈内降雨，仅轻微调制外围；当前整体雨量再乘 0.90，稍微削弱降水。云底保留纹理，按降雨能见度与云面距离计算遮蔽；强风本身不再直接抹平云纹理。
- 轻碎屑、中等杂物、大板片分别在 95、137、155 kt 起飞，总量为上版的约三分之一；保留不同跟风速度、惯性、翻滚与高度，以及海风下更少的供应量。相机水平移动从粒子位移中扣除，高度使用世界海拔，转动通过世界坐标投影体现；暂停时飞行也不会带着杂物走。

## 场景与简化增水

默认观测点为临海公寓六层，距地坪 18 m、海拔 18.9 m，距常态海岸约 40 m。可在地图点选五座楼房，或从主视窗下方切换楼房和楼层；各楼支持的最高楼层不同，最高 40 层。风雨随观测点移动。增加多座 29–125 m 高的住宅，视场角扩大到 58°，方位可调 -75° 至 95°，俯仰 -40° 至 38°。默认视野仍以住宅和海面各占一侧。

简化增水随本地持续风增强，170 kt 对应约 3 m（约一层楼高度；实际淹深需扣除地坪海拔），200 kt 约 4.3 m，硬上限 4.5 m。上升时间常数为 40–65 模拟分钟。高水位保留穿过风眼；170 kt、30 kt 移速情形中，中心离开至少 500 km 后才开始回落，之后按峰值水位约 6 模拟小时的速度缓慢退去。时间倍率同时影响涨水与退水。主界面及全屏显示相对常态水位的当前上升米数（精确至 0.01 m）、涨退趋势与速率。海岸设有固定海拔阶梯：步道 0.25 m、道路 0.55 m、住宅前场 0.90 m、内街 1.70 m、高处住宅台地 2.90 m、内陆高地 4.65 m，短坡和楼梯连接。海水只升降，地形高于水面时保持露出，水位超过后依次淹入；建筑与观测高度计入地台海拔。浅水区可透出淹没的台阶和路面标线，较深水区逐渐变浑；界面显示已漫过的台阶与下一阶门槛。白色细带移动表现海面浪带，白斑表现雨水击打；不计算波浪起伏、破碎、真实海岸水动力或结构力学。增水数值仅用于视觉演示，不是风暴潮预报。

新增风响应景观：旗布、电线、草木、垃圾桶盖。环境杂物总体减少约 30%，海上来风时进一步降至陆上来风约 22%。风毁按每个物体本地瞬时阵风和累计受风时间计算，树木、路灯、窗户的门槛分别为 145、155、160 kt；超过门槛后另叠加随超出风速三次方增长的损伤速率：高出约 20 kt 时，所有默认耐受力的物体均在 48 个模拟秒内完成风毁；各物体耐受力差异、暂停与时间倍率继续生效。包含树折/拔根、桶和路牌翻倒飞走、窗户碎裂、路灯折毁、护栏变形及旗布脱落。此为简化视觉效果。点“恢复”清除累计损伤、修复景物，保留台风和水位；“重置”复位全部。

全屏下通过“观测显示”独立开关风速风向、雨量、当前水面上升和小地图。风速可切换持续风/阵风，地图可切换持续风场着色，并支持拖动与缩放。

地图按公里比例表示风场，住宅区按实际约 1.8 km 的尺度绘制；楼房定位符号为便于识别而放大，不代表建筑的真实占地。

## 手机与平板

支持横竖屏与安全区布局，主视窗单指拖动环视、双指捏合缩放。“视角”展开临时操作面板，含上帝视角、俯瞰、缩放、去雾、归中和恢复；点选后收起。进入上帝视角后，左下角半透明摇杆控制水平飞行，右下角“升 / 降”改变高度；可同时环视和移动。松手、切换视角、旋转屏幕或离开页面会停止触屏移动。横屏时摇杆与升降键贴两侧，操作条居中贴底。

三种地图均可单指平移、双指缩放；开启“移动风暴中心”后才允许单指设置中心，双指缩放不会触发风暴定位。全屏读数压缩为顶部窄条，可用“读数”隐藏；小地图默认收起，点“地图”展开，此时暂时隐藏飞行控件以免遮挡和误触。“视角 → 显示选项”保留各读数、小地图和持续风 / 阵风选择。“净览”隐藏所有覆盖层，只留“显示”按钮恢复。触屏设备不会请求鼠标锁定。不支持原生全屏的浏览器自动使用页面全屏。手机端降低渲染像素比和阴影贴图尺寸以减轻负载，天气计算保持一致。

## 操作

画面工具栏的“去除雨雾”只降低整体雾遮蔽，保留雨丝、碎雾与运动白色雾带；显示的气象能见度和风雨计算不变。滚轮最广为 0.35 倍（垂直视场约 115°），最窄为 12 倍（约 5.3°），广角端有轻微桶形镜头畸变和边缘暗角。

全屏时在场景上移动鼠标即可环视，无需按住；移动到工具栏、地图、菜单时暂停环视，便于操作。全屏小地图新增“拖动风暴中心”开关，与普通地图及大地图的开关同步；关闭后恢复地图平移。

晴空和低降水时采用较强的太阳直射、蓝天漫射与地面反弹光，建筑、树和棚屋有真实投影。阴雨时光线转冷、对比减弱。海面加入视角相关的天空反射、掠射角水色过渡与太阳碎光；细纹理随距离淡出以减少远处闪烁，仍不计算波浪起伏或破碎。

主视窗滚轮在 **0.35–12 倍**间缩放，采用真实透视视场角转换；点击倍率恢复 1 倍。高倍率下拖动灵敏度降低，便于看远处景物。

“上帝视角”从当前楼层视点进入无碰撞自由飞行：点击视窗后 **WASD** 前后左右，WASD 取视线的水平方向，俯仰不改变高度；**Q / E**（或 C / 空格）垂直下降 / 上升，**Shift** 四倍加速。可在全空间移动，包括穿过建筑或地面；拖动 360° 环视，俯仰 ±89°。下方速度滑块为 1–300 m/s，带标度。飞行不受天气暂停和时间倍率限制。实际相机位置参与风雨采样，地图显示自由视点及缩放后的视场扇形。“俯瞰楼群”直接到海岸上空；“返回楼房”或重新选楼回到原楼层，“归中”把自由视点移回所选楼房。

新增 31 座建筑、更多车辆 / 长椅 / 花池，总计 59 棵不同高度的棕榈、阔叶、针叶、窄冠树，全部保留随风弯曲与断裂 / 拔根。海边五座轻型棚屋在本地风超过 120 kt 后按暴露时间受损，墙板倾倒、屋顶掀起并飞走；恢复按钮重建。雨滴的物理终速和通量与显示速度分开；平移采用实际经过时间，避免低帧率拖慢雨滴、雾带及飞行杂物。眼墙下缘以环形云底连接内外壁，保留风眼开口，使用有纹理的云层材质，以降雨消光遮蔽。连续低云基准高度为暴风圈内 400 m、眼墙 280 m、外围阵雨 650 m；云底在约 3.3/5 km 尺度上缓慢起伏，幅度不超过 ±35 m。

研究依据、实测数值、完整公式及参数适用范围见 **[风雨与径向风场说明](docs/weather-model.md)**，包含台风雨滴谱、地面落速、光学消光、成熟眼降水和飞机径向风剖面资料。明确区分观测结论与本版的视觉参数。

“风场色标”在小地图下方、大地图工具栏与全屏小地图中均可打开。预设包括海岸默认、经典气象彩虹、Viridis、Inferno、灰阶与风级分段。可编辑 0–300 kt 的风速节点、颜色拾取器与 HEX，增删节点并切换连续 RGB / 分段色阶；同速双节点可形成跳变。三种地图及其图例共用同一映射，范围外延续端点颜色，不改变实际风场。当前色标自动保留，可保存到“我的色标”，或通过 JSON 文本导入导出；风速色标使用 `unit: "kt"` 和 `nodes: [{value, color}]`，不直接套用红外温度节点。

所有滑动条均有数值标度，楼层和风圈半径的标度随有效范围更新。时间倍率为 1–1000 对数滑块，1、10、100、1000 倍等距；数字框保持实际倍数，方向键按 1 倍微调，Home / End 到两端。

风暴潮漫过步道与道路后，积水中会出现瓶罐、木板和箱体。小件漂得更快、大件漂得更慢且转向更迟缓；漂流速度随风速增强，并受浅水限制。漂浮物会绕阻楼房，在水深不足或退水时搁浅；“恢复”和“重置”会复位漂浮物。正北方增加三层低多边形远山，随场景雾效与能见度自然显隐。

1. 地图默认拖动平移，点击楼房选择观测点；只有开启“移动风暴中心”才可点击或拖动设中心。滚轮缩放，地图宽度 0.24–3200 km，也可用滑条调节。放大地图可查看实时持续风速热力图和风矢量；风场仅有轻微平滑不对称，越强的核心越对称。
2. 台风强度、四个半径、中心东西/南北距离、移动方向/速度、时间倍率均支持滑条。独立雨强可单独调节。中心数值控制在“精调中心位置”内，以海岸公寓为固定原点；地图读数相对所选楼房。数值框按 Enter 或移开焦点提交。
3. 拖动方向转盘调整移动去向；转盘聚焦时方向键微调，Shift 为每次 15°。0° 北、90° 东、180° 南、270° 西。转盘、数字框和滑条同步。
4. 点击“开始推进中心”自动移动，时间倍率 1–1000 倍（对数滑块，标注 1/10/100/1000×），同时影响时钟、外围阵雨切换、风暴潮涨退及累计受风损伤；连续对数风雨波动按现实秒推进，即使中心固定也生效。移速为 0 时首次启动设为 15 kt。暂停推进保留移速对风场的贡献；全局暂停冻结天气、增水与中心移动。
5. 拖动主视窗或按方向键观察。六个快速体验按钮保持当前强度和结构参数，停止中心推进；“归中”只复位视角。
6. 地图的“楼群”放大至五座楼房，“观测点”移回当前楼房，“全风场”显示完整外围圈。地图聚焦后方向键默认平移，开启移动风暴后才移动中心，Shift 加速。

桌面端控制区滚动时主视窗保持可见；手机端纵向排列。风雨声默认关闭。

## 源码和验证

需要 Node.js 22 或更新版本；无需安装 npm 依赖。修改 `src/` 中的源码后运行：

```powershell
node build.mjs
node --test tests/*.test.cjs
```

开发预览：`node serve.cjs`，访问 `http://127.0.0.1:8787`。最终 HTML 不依赖服务器。

### 静态托管

`node build.mjs --pages` 会额外生成 `_site/index.html`，内容与仅内置参数版 `台风模拟器.html` 完全一致，没有编辑器入口，也不读取外部配置。两套 HTML、编辑器和配好的 JSON / JS 同时复制到 `_site/`，各自可单独访问或下载。修改 JSON 影响可配置版；修改线上首页的内置默认需要调整 `src/` 并重新构建。GitHub Pages 通过 [Pages 工作流](.github/workflows/pages.yml) 在每次推送到 `main` 时自动构建、运行全部测试并部署；也可以在 Actions 中手动运行。仓库 Settings → Pages 的发布来源应设为 **GitHub Actions**。

## 风眼云墙与移动雨幕

风眼中心约 100 kt 雨停时云墙便已形成，初期受厚云、平淡光照和散射遮挡，云隙及能见度改善后才逐渐显露；较强系统云顶更高、内壁更完整，保留暗底、亮顶和向外倾斜的体育场形结构。风眼内缘、眼墙外缘均直接使用设置中的公里数据，固定在风暴中心，随风暴平移；自由飞行也可接近或穿越云墙。云顶约 11.5–17 km，为可视化设定。大风眼开口更宽、墙顶仰角更低，边缘观察时近侧更高、更近。远景使用对数深度并依照能见度添加空中透视。参考 [NOAA/AOML 多里安风眼实拍](https://www.aoml.noaa.gov/eye-of-dorian-during-intensification/)，照片仅作形态参考，全部云体由程序生成。

雨丝与运动雾带使用空气位移减去相机位移，包含 WASD 水平飞行及 Q/E 升降；雨线方向和长度也按相对速度变化。相机移动不受天气暂停影响；天气暂停后，移动视角仍会穿越世界中静止的粒子。粒子循环支持单帧跨越多个范围，切换楼房或瞬间跳转视角会重新定位粒子范围。

新增验证：`node --test tests/*.test.cjs`，包含实际尺度、开口仰角、太阳遮挡、风暴平移、相机相对粒子运动、配置回退、公式附录完整性和随机对数波动，共 18 个测试文件。

云墙内壁严格限制在风眼内可见，眼墙和暴风圈使用连续低云顶，圈外沿用原天空。内壁为连续螺旋纹理，按最大风速处的角速度（Vmax/RMW）随模拟时间逆时针旋转，时间倍率与暂停均生效，修改参数不会跳相位。眼内约 0.75–1.5 km 低云和 2.7–3.8 km 中云采用同一程序密度场控制天空云隙和内壁遮挡，强度越高越稀薄，190 kt 起完全清空。强风雨时天空与场景雾色在相同输出颜色空间融合，兼容普通视角和广角后处理。

浏览器触屏回归检查（需本地 Playwright 与 Edge）：`node tests/mobile-layout.browser.cjs`，覆盖普通与全屏、横竖屏、摇杆触控、读数与地图、净览及视角面板。

配置浏览器验证：`node tests/config.browser.cjs`，覆盖内置版无编辑器且不受外部配置影响、可配置版 JSON 优先与 JS 回退、公式附录搜索 / 分类 / 完整源码与手机布局、默认计算一致性、数值 / 静态和动态文案 / CSS / GLSL / 公式覆盖、无效与缺失配置回退、编辑器修改 / 两种格式导出 / 跨窗口预览、手机布局，以及本地 `file://` 自动读取与预览。另有 `guide.browser.cjs` 和 `compact-layout.browser.cjs` 检查引导、紧凑布局和分类动画。

`node tests/cloud-ceiling.browser.cjs` 检查云底消光、纹理恢复、1.3 倍当地持续风搬运及暂停；`node tests/mist-curtains.browser.cjs` 隔离检查雾墙的实际渲染、尺寸差异、风向、搬运与形变时钟、暂停后平移 / 升降 / 环视及手机横屏。WebGL 浏览器测试应依次运行，避免 GPU 争用。

本地最新风雨调节：雾墙横风宽度再扩大 6 倍（约 40–162 m），120 / 150 kt 雨雾浓淡约每秒 2 / 3 次，随后趋近 3.5 次。细雨显示速度随风增强至 200 kt 的 2 倍，拖尾至少保留同雨量静风长度的一半；雨滴不透明度再降低 20%。这些是视觉参数，物理雨量与平均能见度标定保持原值。

雨雾起伏增幅（2026-10-24）：频率在基准值的 70%–130% 内连续变化（±30%），用多尺度相位扰动形成不等间隔的快慢变化；120 / 150 kt 的约 2 / 3 Hz 为长期平均，3.5 Hz 为平均频率的渐近上限，瞬时值可超过该值。波长保持基准尺度，分别积分雨与雾的变化相位，避免跳变。竖向雾墙沿运动方向的厚度也按各自相位在 30%–170% 之间平滑伸缩；横风宽度和贴地薄雾尺寸保持此前设定。建筑避让按最大伸展范围判断，暂停冻结频率相位与厚度伸缩。这些仍为视觉参数。

滑条交互：最大持续风速与独立雨强滑条的可拖动高度扩大到 32 px，保留 4 px 可视轨道；刻度区域禁止文字选择，刻度文字不拦截指针，避免拖动时误选下方文字。数值输入框仍可编辑和选择文字。

设置栏开关统一使用横排“设置”与实心正三角形，依据 aria-expanded 旋转 90°。桌面收起栏宽 88 px，手机保持整行按钮。布局动画期间持续渲染到原有 GPU 缓冲区，按实时宽高比更新投影，保留相机中心朝向；结束后仅在下一次绘制前调整一次渲染分辨率。ResizeObserver 不直接清空或重建主画布；viewportDiagnostics() 可核对缓冲区次数及中心视线。

设置按钮在展开和收起动画中始终按侧栏当前内容宽度铺满，两端持续对齐；收起状态不预先给按钮设置固定宽度。

## 风雨声音

风雨声音量：默认主音量 50%，雨声与风声独立混音，强风时进一步增强风声；左侧观测区右下方提供 0–100% 滑条，0 为静音，仍需点击“开启风雨声”后播放。40 px 高的原生滑条支持触屏、鼠标和键盘，文字不参与选择，控件位于场景外避免误触视角。音量平滑切换，重置模拟保留所选音量。

声音当前实现：采用用户最终选定的 01 程序雨滴片段，18 个 24 kHz 内置采样随回放速度随机变化，有效滴声约 34–63 ms；不依赖 tmp 或外部媒体。间隔服从泊松分布，密度为 25(R/10)^0.8 次/秒；音量按半径 24 m 平面均匀落点和 1.2 m 听点高度的三维 1/d 声压衰减生成，约 −24.5 至 +1.5 dB，低音量更常见。滴声随雨量增响放缓，7–24 mm/h 提前交叉至连续雨声。实际 RMS/峰值 dBFS 在试听报告中列出。150 kt 以上风声增益更陡，尖啸独立混音，155 kt 起从零增强，事件持续 4–10 秒、间隔 1–4 秒，音高只随瞬时风速变化，音量、谐波和气流音色随机变化；每次增益在 −20 至 −10.5 dB 之间选择，单次内部再叠加 −10 至 +2.5 dB 的平滑随机起伏和宽带漏风气声。调音参考了窗缝阵风、无风细雨两段公开实录的频谱与包络，来源及限制见天气模型文档；低沉轰鸣随强度增加并混入失真。输出使用无共享增益包络的软峰值保护，避免风声压缩器联动压低雨声。默认音量仍为 50%。


云雨与声音规则更新：降雨开始前先形成覆盖天空的程序云纹理，停雨后才逐渐清云。外围允许无雨阴天，越向内总体阴天占比越高；云盖比稳定降雨向外围的过渡区延伸更远，保留与暴风圈持续降雨的平滑衔接。小于 7 mm/h 只播放随机、以轻滴为主的离散滴声，音量和密度随雨量增加；7–24 mm/h 平滑交叉至连续雨声。雨声音量按实际雨滴世界飞行速度增强，不随相机移动而变化，仍独立于风声压缩器。150 kt 以上风声增长更陡；155 kt 以上渐入 4–10 秒的随机窄缝式尖啸和 28–210 Hz 的独立低沉轰鸣，轰鸣失真混入比例随强度增加。默认音量仍为 50%。本轮增加真实 Web Audio 输出的波形、频谱及阈值验证，试听片段和测量报告写入 tmp/audio-validation/。

声音回归验证：`node tests/audio-characteristics.browser.cjs` 在浏览器 OfflineAudioContext 中直接渲染生产声音引擎，覆盖 13 档雨强、9 档风速、65 mm/h 混合风雨、7/24 mm/h 两侧、从 0 连续增雨、3 组随机尖啸种子、70 秒连续尖啸起伏及漏风能量，以及 100% 音量极端工况。检查实际 PCM 的能量、雨声音色频段分布、尖啸在混音中的谱峰和输出峰值；导出同增益 WAV 试听，不按片段单独归一化。页面接入与控件由 audio.browser / weather-audio-smoke.browser 检查。声音代码位于 src/sound.js，audioDiagnostics() 可检查当前声层及事件计数。

# 风雨与径向风场：研究依据及当前近似

更新：2026-10-23。公式在 `src/model.js`；可配置版的编辑器提供全部表达式和完整源码。这里区分观测结论、物理关系与为本模拟器选取的参数。它们并非一套经特定台风资料拟合的预报模型。

## 1. 雨滴变细、浓度增加与白色雨幕

Tokay 等（2008）分析了 7 个热带气旋的雨滴谱：小到中等雨滴浓度较高，最大直径很少超过 4 mm；在 40 dBZ 附近，报告的数浓度约为 700±100 个/m³、液态水含量约 0.90±0.05 g/m³、雨强约 18.5±0.5 mm/h。这支持“台风雨不能只画成稀疏的大雨滴”，**不能证明所有降雨在 110 kt 都会雾化**。

本版按用户指定，把 **65–110 kt** 设为连续视觉过渡区。细雨在 110 kt 主要呈现为密集短点和白色雨幕；这里的“雾状”指远小于屏幕分辨率的细雨观感，仍然计算降雨通量，不将全部水解释为云雾的微米级液滴。

```text
m = smooth(65, 110, U)                       # U：本地风速，kt
d0 = (0.85 + 0.40 ln(1 + R/10)) (1 − 0.82m) # 尺寸尺度，mm
x_i = 0.125 + 0.25i, i=0…15
D_i = max(0.01, d0 x_i) / 1000               # m
w_i = x_i² exp(−3x_i)                        # 未归一化的离散谱形
```

谱形是简化 gamma 形状；**d0 对风速的缩小关系与阈值是可调的视觉假设，不是论文回归式**。保持雨量 R 不变时，用第 2 节的通量约束重新计算浓度。因此雨滴变细不是凭空减少水量。渲染抽样数量从原数量逐渐增加到约 2.18 倍，曝光拖尾缩短，最大池 48000 条；每条仅代表粒子群，屏幕抽样数不等于物理数浓度。

大雨雨幕与强风细化分开：15–100 mm/h 逐步增加运动雨幕，即使只有较弱风也存在。浓淡带随风平移并下沉；较弱风时取风速约 0.48 倍的图案漂移和雨滴体积加权落速约 0.48 倍的下沉，高风时逐渐更贴近水平风向。它们是浓度图案的速度，不是每一滴水的速度。相机移动仍从雨滴和雨幕速度中扣除。

飓风 Fran、Frances 的多普勒观测发现亚公里尺度的边界层相干结构，其中 Frances 的近地面线状结构波长约 400–500 m，能组织风速与阵风。但这不是“弱风大雨中的可见白条速度”的直接测量。本版雨幕纹理的间隔、宽度、对比度及漂移比例均属视觉参数；没有把这些强飓风观测冒充为白条的定量标定。目前未找到可据以唯一确定该观感速度的通用实测公式。

## 2. 固定雨量时，为何能见度变化

旧版含有独立的 `(风速/14)²` 项和额外强风雾化惩罚，是经验视觉函数，**并非平方阻力公式推导**。

阻力取决于雨滴相对空气的速度，而不是相对地面的风速。在均匀水平气流中，雨滴随空气平移；仅增加水平地面风速，不足以直接推出竖直终速下降。湍流、垂直气流、雨滴破碎、海水飞沫及凝结雾可改变情况。

Montero-Martínez 与 García-García（2016）的多年地面观测发现：大风中，既有小雨滴超终速的情况，也有 1–2 mm 雨滴低于终速的情况，落速分布变宽。Thurai 等（2018）在强湍流超级单体个例中测得平均落速可比静空气终速低约 25–30%。后者是特定强湍流情形，不能把 25–30% 当作所有台风的固定修正。本版未额外强加一个风速平方的落速修正。

本版用雨水体积通量和几何光学消光约束：

```text
F = R / 3 600 000                            # 降雨体积通量，m/s
v(D_mm) = 9.65 − 10.3 exp(−0.6 D_mm)         # D ≥ 0.6 mm，m/s
v(D_mm) = v(0.6) (D_mm/0.6)^1.15             # 更小雨滴的连续近似
C = F / Σ[w_i (πD_i³/6) v_i]
N = C Σw_i                                  # 数浓度，个/m³
LWC = 10⁶ C Σ[w_i πD_i³/6]                   # 液态水含量，g/m³
v_volume = Σ[w_i D_i³ v_i] / Σ[w_i D_i³]
β_rain = C Σ[w_i πD_i²/2]                    # Q_ext ≈ 2；1/m
β_background = ln(20) / 11000
MOR = clamp(ln(20)/(β_background + β_rain), 55, 11000) # m
```

终速主式来自 Atlas、Srivastava 与 Sekhon（1973）；小于 0.6 mm 的分支是本版连续近似，不是完整 Beard 微物理算法。对雨滴远大于可见光波长的情况，取消光效率约 2。`MOR` 使用透射率剩 5% 的定义，分子为 ln(20)≈2.996；不能与 2% 对比阈值对应的 3.912 混用。

Montero-Martínez 与 García-García（2025）的墨西哥两站光学雨滴仪研究详细列出 MOR、雨滴谱第二矩消光和第三矩降水通量的联系，实测大雨时 MOR 可低于 1 km。该研究也指出仪器对细小滴的漏测问题；雨强与能见度不是一条普遍唯一曲线。

在本版**指定的细化假设**下，固定 50 mm/h 的示例为：

| 本地风速 | 尺寸尺度 d0 | 体积加权落速 | 数浓度（近似） | MOR（近似） |
| --- | --- | --- | --- | --- |
| 65 kt | 1.57 mm | 7.60 m/s | 417/m³ | 1249 m |
| 80 kt | 1.23 mm | 6.86 m/s | 947/m³ | 917 m |
| 95 kt | 0.62 mm | 4.45 m/s | 11772/m³ | 315 m |
| 110 kt | 0.28 mm | 2.20 m/s | 247169/m³ | 73 m |

这组结果用于说明所选参数的后果，**不是观测数据**。强风端的浓度增长很大，不能声称已被上述台风雨滴仪数据验证。若希望只改变视觉、保持另一种真实雨滴谱，可在编辑器改 `rain.effectiveDiameter`，或直接改 `weather.visibility`。晴空零雨时，风再大也不再单独压低能见度。

未解析独立的云雾凝结、湿气溶胶、海盐飞沫谱、垂直气流、碰并破碎过程及建筑附近湍流；渲染中的指数平方雾和半透明雨幕仍是显示近似，并非光线输运求解器。“去除雨雾”仍只影响画面，保留气象读数。

## 3. 从眼区进入眼墙时的降雨

Houze（2010）的综述描述了成熟眼内下沉、边界层上方层云，以及向外倾斜、带强降水的眼墙。这支持干燥眼与强降水环分离；**台风强度本身不足以唯一决定眼区降水**，还受眼墙置换、涡旋不对称、垂直切变等影响。

本版保留强度的连续发展：67 kt 以下无眼；67–100 kt 眼中心逐渐减少降雨，弱眼保持雨。随着 100–150 kt 增强，干燥眼区向设定的眼墙云底内缘扩展：

```text
c = smooth(100,150,I)
r_start = E (0.25 + 0.75c)
r_end = E + clamp((W−E)(0.18−0.12c), 0.25, 3) # km
drying = smooth(67,100,I) (1−smooth(r_start,r_end,r))
rain = innerRain × (1−drying) × independentRainStrength
```

E 为眼半径、W 为眼墙外界半径。到 150 kt 及以上，**整个 r≤E 的眼区均保持干燥，越过眼墙内缘后才增加降雨**。默认 E=15、W=40 km 时，15 km 内无眼墙降水，15–16.5 km 为连续但很陡的雨墙入口；此前的整个眼内渐增已去除。100–150 kt 采用更宽、更湿的过渡，不会在某个风速突然换模型。暴风圈内维持相对平坦的持续降水，接近眼墙外沿较快增大；外围随机阵雨可偶尔超过眼墙。

以上阈值和雨强幅度为可调场景参数，未从某个风级统计出精确通用分布。降雨是近地面二维径向模型，尚未随自由飞行高度切换成三维降水剖面。

## 4. 持续风的径向曲线

Willoughby、Darling 与 Rahn（2006）使用 493 条质量控制后的飞机观测剖面研究参数化风场：内侧幂律、外侧指数衰减；较强飓风往往需要快、慢两条指数。摘要报告内侧指数平均约 0.79，快速尺度 25 km 可取得良好效果，缓慢尺度平均约 295 km；它也指出若干已有曲线在峰值附近偏宽、外侧衰减过快。

本版采用该**函数族的启发式地面风适配**，并非逐式复刻论文的完整拟合关系，也未把飞行高度风当作实测地面一分钟风：

```text
q = r/RMW
n = 0.79 + 0.65 smooth(67,185,I)
A = 0.10 + 0.50 smooth(83,185,I)
X_fast = clamp(2(W_effective−RMW),8,80)       # 默认成熟眼墙为 24 km
L = clamp(0.1(W_effective−RMW),0.5,4)
b = 0.015; p_outer = 0.045
X_slow = max(X_fast, (influenceRadius−RMW) /
             ln((1−b)(1−A)/(p_outer−b)))

内侧：p = q^n + (1−q^n)smooth(0.78,1,q)
外侧：s = r−RMW; d = s−L(1−exp(−s/L))
      p = b + (1−b)[A exp(−d/X_fast) + (1−A)exp(−d/X_slow)]
V = Vmax p
```

峰值处内外斜率都趋近零，中心风速为零。双指数在眼墙附近衰减较快、向外保留缓降尾部。地图上的眼墙、暴风圈及影响圈不再强制把曲线切成几段水平平台。影响圈半径用于约束慢衰减尺度，外围仍有弱背景风；没有在圈线处截断风场。风圈是可编辑的场景边界，不是强制的 34/50/64 kt 等风速圈。轻微方位不对称和移速向量叠加继续保留。

因用户可独立调整各个半径，慢衰减尺度通常不同于观测样本的 295 km 平均值；当前 n、A 对强度的关系、峰值肩部和尾部弱风值均是本版选择，不能表述为论文的精确经验公式。
